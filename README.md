# 🎬 Золотой терабайт (Golden Terabyte)

**Локальная офлайн-кинотека нового поколения для Windows 10/11**

«Золотой терабайт» превращает обычные папки с фильмами, сериалами и концертами на ваших жёстких дисках и SSD в визуальный домашний кинотеатр в стиле современных стримингов — но с одним главным отличием: всё хранится локально на ваших накопителях и работает **на 100% без интернета, серверов и подписок**.

### ✨ Основные возможности

* **Премиальный каталог:** тёмный интерфейс с вертикальными постерами, широкими фонами, описанием сюжета, актёрами, режиссёрами и рейтингами (IMDb / Кинопоиск).
* **Умная структура:** отдельные разделы для фильмов, сериалов (с сезонами, сериями и прогрессом просмотра), мультфильмов, документального кино, ТВ-передач и концертов.
* **Технический анализ через FFprobe:** автоматическое определение честного разрешения (`720p`, `1080p`, `4K UHD`), кодеков, метаданных `HDR` / `Dolby Vision`, аудиодорожек, языков и субтитров прямо на карточках.
* **Воспроизведение без компромиссов:** запуск видео через ваш системный плеер Windows по умолчанию (`MPC-HC + madVR`, `PotPlayer`, `VLC` и др.) с сохранением аппаратного ускорения видеокарты.
* **Полный контроль над данными:** база данных `SQLite` и постеры хранятся отдельно от видеофайлов. Исходные фильмы не перемещаются и не изменяются. Предусмотрено резервное копирование и восстановление библиотеки.
